Frequently Asked Questions

Everything you need to know about mining on {{ footer.pool_name }}.

Use the following stratum URL:

stratum+tcp://pool.lotusia.org:3334

Credentials:

  • Username: Your Lotus (XPI) payout address
  • Password: x (any password works)

Optionally append a worker name: address.workername

The pool fee is displayed in the footer. It is deducted from the gross block reward before miner payouts.

We use PPLNS (Pay Per Last N Shares). The payout window covers the last N difficulty units of work, where N = {{ n_multiplier }}× network difficulty.

  • Shares are difficulty-weighted (a 2× diff share counts as 2 shares)
  • The window extends across round boundaries
  • Early leavers receive less; late joiners receive less (fair for everyone)

Payouts are processed automatically after a found block matures ({{ min_confirmations }} confirmations). The scheduler runs periodically to process matured blocks.

The minimum payout threshold is displayed on the dashboard. Outputs below this threshold are carried forward to the next payout batch (no dust is lost).

Any stratum-compatible miner that supports the Lotus (XPI) algorithm will work. Popular options include:

  • CPUMiner (for CPU mining)
  • Any ASIC miner with stratum support
